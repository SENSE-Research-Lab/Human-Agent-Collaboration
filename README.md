# Replication Package

**Paper Title:**

_When Code Authors Are Agents: A Large-Scale Study of Human–Agent Collaboration in Pull Requests_

## Overview
This repository provides the replication package for the above paper. It includes the datasets and Jupyter notebook used to reproduce the analyses presented in the study.

The data consists of pull request (PR) records related to human-authored contributions. The datasets for agent-authored were originally obtained from the repository of the source authors, and access links are provided within the notebook. Psycholinguistic analysis was also conducted externally on LIWC and the data can be found on [Zenodo](https://zenodo.org/records/19098786?token=eyJhbGciOiJIUzUxMiJ9.eyJpZCI6IjEzNTRkMGQzLTFiNzItNGQ4Yi04M2E3LTI0ZmZlOWJhNjFkYSIsImRhdGEiOnt9LCJyYW5kb20iOiI5YWNhZjJmMGFhNDk1ZjhiNGI2NTgzMjA4ZjZjYWU1YyJ9.pb06AfAWQn3pE_9VKnLcLZS7KAQkBlIeEYhOUSxF5lVs8TnQ5tJp3hGZlmxNZrYVoqJtpOWKJNMJmIJpVs9xiA) 

The package supports an empirical investigation of the differences between agent- and human-authored PRs.

## Usage Notes
* All data has been fully de-identified to preserve participant anonymity.
* The dataset enables replication of the analyses presented in Section 3 of the paper.
* Statistical analyses were conducted using Python-based data analysis libraries.

## Research Framework
This study examines human–agent collaboration across three key dimensions:
* **Integration outcomes**
* **Structural characteristics of patches**
* **Collaboration and communication signals**

The analysis is guided by the following research questions:

**RQ1:** How do development outcomes differ between agent-authored and human-authored pull requests?

**RQ2:** How do patch characteristics differ between agent-authored and human-authored pull requests?

**RQ3:** How do collaboration and communication patterns differ in agent–human versus human–human code review interactions, and how do these patterns relate to merge outcomes?
