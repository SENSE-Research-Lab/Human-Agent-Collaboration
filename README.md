# Replication Package

Paper Title: 

_When Code Authors Are Agents: A Large-Scale Study of Human–Agent Collaboration in Pull Requests_

## Overview
This repository contains the replication package for the above paper. It includes the Human PR-related data and jupyter notebook file used in performing analysis related to the research.

Links to the Agent PR-related data used have been hardcoded as they were downloaded from the repo of the original authors. 

The data collected was used in investigating the characteristics and differences in Agent and Human-authored PRs.

## Usage Notes
* All data has been fully de-identified to preserve participant anonymity.
* The dataset supports replication of the analyses presented in Section 3 of the paper.
* Statistical analyses were conducted using Python-based data analysis libraries.
