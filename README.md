# Replication Package

Paper Title: 

_When Code Authors Are Agents: A Large-Scale Study of Human–Agent Collaboration in Pull Requests_

## Overview
This repository contains the replication package for the above paper. It includes the Human PR-related data and jupyter notebook file used in performing analysis related to the research.

Agent PR-related data have been hardcoded as they were downloaded from a cloud repo.
